💡 Tips

  • DPI only affects print density — the pixel dimensions you see on screen never change.
  • 300dpi is the most commonly required value for print shops and publishers.
  • 72dpi is plenty for web images — it has no effect on file size.

Frequently Asked Questions

Does changing DPI reduce image quality?

No. Pixels are never redrawn or recompressed — only the DPI metadata inside the file is patched, so the original quality is 100% preserved.

Does the pixel size of the image change?

No. Width and height in pixels stay exactly the same. DPI is only a print-density value; the image looks identical on screen.

Which formats are supported?

JPG and PNG. DPI is written to the JFIF header for JPG and the pHYs chunk for PNG.

Are files uploaded to a server?

No. All processing happens entirely in your browser and files are never sent to a server.

Frequently Asked Questions

Can I rename any file type?

Yes, any file type is supported, not just images. Only the filename changes — file contents are untouched.

How does sequential numbering work?

Files are numbered in list order starting from your chosen number, zero-padded to the digit count you set. For example: 001, 002, 003.

How do I get the results?

All renamed files are bundled into a single ZIP you can download at once.

Are files uploaded to a server?

No. All processing happens entirely in your browser and files are never sent to a server.

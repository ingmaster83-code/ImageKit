ICO → PNG 변환 사용법

  1. ICO 아이콘 파일을 업로드합니다.
  2. 포함된 크기 중 원하는 것을 선택합니다(ICO는 여러 해상도를 담습니다).
  3. PNG로 다운로드합니다.

ICO 형식

ICO는 윈도우 아이콘·웹사이트 파비콘용 형식으로, 한 파일에 16×16·32×32·48×48 등 여러 크기를 담습니다. 이미지 편집이나 다른 용도로 쓰려면 PNG로 추출합니다.

💡 Tips

  • ICO 파일에는 여러 크기의 이미지가 포함되어 있으며, 브라우저가 선택한 크기로 변환됩니다.
  • PNG는 투명도를 지원하므로 아이콘의 투명 배경이 보존됩니다.
  • PNG를 ICO로 변환하려면 PNG → ICO 도구를 사용하세요.

자주 묻는 질문

ICO 파일이란 무엇인가요?

윈도우 아이콘과 웹 파비콘에 쓰는 형식으로, 여러 해상도를 하나에 담을 수 있습니다.

PNG → ICO로 변환도 가능한가요?

네. 파비콘을 만들려면 PNG → ICO 변환 도구를 사용하세요.

ICO에 여러 크기가 있으면 어떻게 되나요?

가장 큰 해상도가 기본으로 추출되며, 원하는 크기를 선택할 수도 있습니다.

투명 배경이 유지되나요?

네. ICO의 투명 영역이 PNG로 그대로 옮겨집니다.

favicon.ico를 편집하고 싶어요.

ICO → PNG로 추출해 편집한 뒤 다시 PNG → ICO로 만들면 됩니다.

이미지가 서버에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 이미지는 서버로 전송·저장되지 않습니다. 개인 사진이나 민감한 문서도 외부 유출 걱정 없이 사용할 수 있습니다.
